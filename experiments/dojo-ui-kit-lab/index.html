OUR FIRST VISUAL LANGUAGE

Built from principles, not borrowed pixels

The reference archives helped define a component taxonomy. The shipped art and icons are newly drawn editable vectors.

Indigo lacquer

Used for deeply framed RPG interfaces, quest cards, and skills, with gold-trimmed selected states.

Warm washi

A calmer document layer for reading, writing, codex pages, and explanatory panels.

Animation language

Opening books, revealing nodes, marking milestones. Animation is optional decoration, never the only way to understand the state.

Reference taxonomy

CraftPix: panels, icon categories, sprite state naming, frame sequences, and modular roads. EAST: shared scale, light direction, and separately managed shadows.
